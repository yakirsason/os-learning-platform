# מבוא למערכות הפעלה

ברוכים הבאים להרצאה הפותחת של הקורס. בהרצאה הזאת נבין **מה עושה מערכת ההפעלה**,
איך היא בנויה, ומדוע היא הרכיב המרכזי ביותר בכל מחשב מודרני - מהשעון החכם שלכם
ועד למרכזי הנתונים שמפעילים את האינטרנט.

בסוף ההרצאה תכירו את המבנה הכללי של מערכת הפעלה, את המושג המרכזי של **פסיקות
(Interrupts)**, את ההבדל בין <span dir="ltr">I/O</span> סינכרוני לאסינכרוני, ואת
**היררכיית האחסון** שמאזנת בין מהירות, גודל ועלות.

## מהי מערכת הפעלה?

<ConceptCard
  title="מערכת הפעלה"

למערכת הפעלה שלוש מטרות עיקריות:

- **נוחות למשתמש** — לאפשר הפעלת תוכניות ושימוש במחשב ללא ידע עמוק בחומרה.
- **ניצול יעיל של המשאבים** — לוודא שהמעבד, הזיכרון וההתקנים עובדים כל הזמן ולא יושבים בטלים.
- **שימוש נכון בחומרה** — למנוע קונפליקטים בין תוכניות שונות שמתחרות על אותם משאבים.

## ארגון מערכת המחשב

המערכת בנויה סביב **מסילת המערכת** (<span dir="ltr">System Bus</span>) - חיבור
משותף שדרכו כל הרכיבים מתקשרים:

- **מעבד אחד או יותר** (<span dir="ltr">CPUs</span>) - מבצעים את הפקודות.
- **בקרי התקנים** (<span dir="ltr">Device Controllers</span>) - כל התקן <span dir="ltr">I/O</span> מחובר דרך בקר המתמחה בו.
- **בקר זיכרון** (<span dir="ltr">Memory Controller</span>) - מתזמן את הגישה לזיכרון הראשי.

<ConceptCard
  title="בקר התקן"

## טיפול ב-<span dir="ltr">Interrupts</span>

כאשר פסיקה מתרחשת, המעבד מבצע רצף פעולות מדויק:

1. **שמירת state** — ערכי ה-<span dir="ltr">registers</span> ו-<span dir="ltr">Program Counter</span> נשמרים במקום ייעודי בזיכרון.
2. **קפיצה ל-<span dir="ltr">Handler</span>** — המעבד ניגש לוקטור הפסיקות ומעביר שליטה לכתובת המתאימה לסוג הפסיקה.
3. **ביצוע הטיפול** — ה-<span dir="ltr">Handler</span> עושה מה שצריך (קורא נתונים מההתקן, מעיר תהליך שחיכה וכו').
4. **שחזור state וחזרה** — ערכי ה-<span dir="ltr">registers</span> מוחזרים, והתהליך המקורי ממשיך בדיוק מהמקום שעצר.

יש שתי שיטות לזיהוי מקור הפסיקה:

<ConceptCard

## ארכיטקטורת המחשב - <span dir="ltr">von Neumann</span>

מודל <span dir="ltr">von Neumann</span> הקלאסי מתאר את מחזור ביצוע הפקודה:

1. **<span dir="ltr">Fetch</span>** — המעבד טוען את הפקודה הבאה מהזיכרון (על פי ה-<span dir="ltr">Program Counter</span>).
2. **<span dir="ltr">Decode</span>** — הפקודה מפוענחת: איזו פעולה ואיזה אופרנדים.
3. **<span dir="ltr">Execute</span>** — הפעולה מתבצעת, ייתכנו קריאות/כתיבות לזיכרון.
4. **חזרה** — המחזור מתחיל מחדש עם הפקודה הבאה.

כל מעבד מודרני מבצע את המחזור הזה **מיליארדי פעמים בשנייה**, עם אופטימיזציות
(pipeline, out-of-order execution) שמאפשרות לבצע כמה פקודות במקביל.

## פעולות <span dir="ltr">OS</span>

מערכת ההפעלה היא **מערכת מונעת אירועים** (<span dir="ltr">interrupt-driven</span>).
היא לא רצה ברצף - היא מגיבה לפסיקות:

- **<span dir="ltr">Hardware interrupt</span>** — מגיעה מהתקן חיצוני (לחיצת מקש, חבילת רשת, סיום <span dir="ltr">I/O</span>).
- **<span dir="ltr">Software interrupt / Trap</span>** — מגיעה מהתוכנה (<span dir="ltr">System Call</span>, חריגה כמו חלוקה באפס).

במצב רגיל המעבד רץ באחד משני מצבים:

## סביבות חישוב

מערכות הפעלה שונות מותאמות למטרות שונות:

- **מערכות בזמן אמת** (<span dir="ltr">Real-time embedded</span>) — רובוטים, רכב אוטונומי, מכשור רפואי. דורשות זמן תגובה מובטח.
- **קוד פתוח** (<span dir="ltr">Open-source</span>) — <span dir="ltr">Linux</span>, <span dir="ltr">FreeBSD</span>. הקוד זמין לכולם, מתפתח באופן קהילתי.
- **מערכות ענן** — <span dir="ltr">AWS</span>, <span dir="ltr">Azure</span>. מנוהלות באלפי שרתים מבוזרים.

## סיכום

- מערכת ההפעלה היא **שכבת תיווך** בין החומרה והתוכנה, שמספקת נוחות ושומרת על שימוש נכון במשאבים.
- התהליך של המחשב מתחיל ב-**Bootstrap** שטוען את הגרעין לזיכרון.
- **Interrupts** הם המנגנון המרכזי של מערכת ההפעלה - כך היא מגיבה לאירועים.
- **<span dir="ltr">I/O</span> אסינכרוני** משפר דרמטית את היעילות - התהליך לא נחסם לשווא.
- **היררכיית האחסון** מאזנת בין מהירות, גודל ועלות באמצעות שילוב של טכנולוגיות שונות.
- **<span dir="ltr">DMA</span>** משחרר את המעבד מהעברת נתונים בצובר.
- **<span dir="ltr">Multiprogramming</span>** ו-**<span dir="ltr">Timesharing</span>** מנצלים את החומרה באופן אופטימלי ונותנים אשליה של הרצה מקבילית.

בהרצאות הבאות נעמיק בכל אחד מהנושאים - נתחיל בתהליכים ובתזמון מעבד.
